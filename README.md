# linux-bash-assignments

Практические задания по Linux, Bash, сетям, Windows Server и другим IT-темам с пошаговым разбором через Claude.

Схема работы:

```text
PDF → анализ задания → пункт 1 → выполнение → проверка → ... → финальная проверка
```

## Структура

| Путь | Что там |
|---|---|
| `CLAUDE.md` | Инструкции для Claude: как разбирать PDF, давать команды и проверять результат |
| `tasks/` | PDF-файлы с заданиями |
| `solutions/<имя-задания>/` | Скрипты и результаты по каждому заданию |

## Как пользоваться

1. Положите PDF с заданием в `tasks/`, например `tasks/lab3-bash-find.pdf`.
2. Откройте репозиторий в Claude Code и напишите: `Разбери tasks/lab3-bash-find.pdf`.
3. Выполняйте шаги по одному и присылайте вывод команд.
4. Готовые скрипты сохраняйте в `solutions/lab3-bash-find/`.

Если используете проект на claude.ai, вставьте содержимое `CLAUDE.md` в инструкции проекта.

## Важно для Windows

В `.gitattributes` для `*.sh` принудительно задано `eol=lf`. Если скрипт всё же сохранился с CRLF и в Linux появляется ошибка `$'\r': command not found`, исправьте так:

```bash
sed -i 's/\r$//' script.sh
```
